## Selected work

### [Quadro — Personal Computer Agent](https://github.com/quadrosema/Quadro-AI-assistant)
My independent project, developed solo since October 2025, brings together agent orchestration, voice, screen understanding, retrieval memory and Windows automation. The current local build uses a stateful LangGraph supervisor, specialist agents, a PySide6 interface and approval gates for destructive actions.

**Long-term direction:** a general-purpose computer agent capable of carrying out almost any task a person can perform on their computer. This is the project's ambition; development is ongoing. The public repository currently contains an **earlier event-driven prototype**, with the current architecture documented separately in its README.

### [AgentGuard — AI-Assisted Transaction Security](https://github.com/atrix187/AgentGuard)
**GSMA MENA Ignite Open Gateway Hackathon finalist** — final results pending.

I owned the **entire AI pipeline** within a five-person cybersecurity team: LangGraph risk evaluation, LLM integration, structured output validation and fail-closed decision handling. The team combined AI reasoning with network verification signals to support approval, step-up verification and blocking decisions.

### [Academic Intelligence Platform](https://github.com/quadrosema/academic-intelligence-platform)
A full-stack academic analysis application combining a saved risk classifier, semantic course ranking and a three-node LangGraph guidance workflow. React, FastAPI and PostgreSQL connect inference to a usable dashboard with persistent prediction and recommendation history. Model evaluation uses synthetic data.

### [Semantic Course Recommender](https://github.com/quadrosema/semantic-course-recommender)
LLM skill extraction, sentence embeddings and cosine ranking, exposed through Flask and a LangGraph workflow with database-backed course data and recommendation logging.
